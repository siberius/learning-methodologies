# Методики навчання: дидактичне проєктування для освітнього ШІ

[![Skills.sh](https://img.shields.io/badge/skills.sh-Install-blue)](https://skills.sh/siberius/learning-methodologies)

Портативний дидактичний скіл для ШІ, призначений для проєктування та аналізу освітніх застосунків. Він поєднує освітні цілі, дії учнів, зворотний зв'язок і докази результатів навчання, допомагаючи втілити ці педагогічні рішення в реальній поведінці застосунку.

## У чому допомагає

- Обирати дидактичні методи під конкретне навчальне утруднення та умови аудиторії.
- Проєктувати корисну ступеневу допомогу (scaffolding), зворотний зв'язок при помилках та самостійну практику.
- Чітко розмежовувати цілі, рівень складності, логічні передумови та свідчення результатів.
- Створювати надійні симуляції та безпечно обмежувати роль ШІ в готовому продукті за потреби.
- Враховувати цифрову доступність (інклюзію), провідну роль учителя, захист даних учнів та технічні обмеження.
- Розрізняти технічну працездатність програми, обґрунтованість педагогічного задуму та фактично спостережувані результати навчання.
- Підбирати відповідні моделі, рівні міркувань та швидкість за офіційною документацією OpenAI, Claude і Gemini.

Довідник методів охоплює сократичний діалог, техніку Фейнмана, зону найближчого розвитку (ЗНР) та навчальне риштування (скаффолдинг), розібрані приклади, практику пригадування та інтервальне повторення, навчання на помилках, метапізнання, дослідницьке навчання, рольові ігри, взаємне та кооперативне навчання, проєкти, «перевернутий клас» та цілеспрямовану гейміфікацію. Це модульні підходи під конкретну мету; встановлення скіла не зобов'язує впроваджувати все одночасно.

## Встановлення

Оберіть україномовну версію через [Skills CLI](https://github.com/vercel-labs/skills). Прапорець `-g` означає встановлення для поточного користувача глобально, `-a codex` обирає агент Codex. Для Claude Code використовуйте `-a claude-code` або пропустіть цей прапорець для інтерактивного вибору асистента:

```bash
npx skills add siberius/learning-methodologies@v1.6.0 --skill metodyky-navchannya --full-depth -g -a codex
```

Тег встановлює вміст цього випуску; гілка за замовчуванням може бути новішою. CLI записує в `skills-lock.json` розв'язаний коміт і хеш встановлених файлів, а `npx skills check` повідомляє про локальні зміни.

Щоб випробувати скіл в одному проєкті, пропустіть `-g`, а потім видаліть копію командою `npx skills remove metodyky-navchannya`. Клієнти, які читають Markdown безпосередньо, можуть використати [автономний файл](metodyky-navchannya.md) без інсталятора; [посібник з використання](docs/USAGE.md) описує ручне розміщення пакета.

## Оберіть форму скіла

- [SKILL.md](SKILL.md) та папка `references/`: нативний модульний пакет із довідниками, які завантажуються за потребою. Зберігайте файли разом.
- [metodyky-navchannya.md](metodyky-navchannya.md): згенерований єдиний автономний файл для агентів, які зчитують інструкції у вигляді одного файлу Markdown. Містить ядро скіла та всі довідники як вбудовані розділи.

Обидві форми підтримуються синхронно з одних вихідних джерел. Редагуйте `SKILL.md` та відповідний довідник у папці `references/`, після чого генеруйте автономний файл. Не змінюйте згенеровану автономну копію окремо вручну.

## Приклад запиту (брифа)

> Використай скіл metodyky-navchannya для створення офлайн-активності про електричне коло для 16-річних учнів. Вони повинні передбачати, як зміна опору впливає на силу струму, та пояснювати логіку міркування. Активність призначена для парного обговорення під керівництвом учителя й має повністю керуватися з клавіатури. Без обов'язкових акаунтів і сторонніх викликів ШІ.

Агент використає цей контекст, добере співмірний рівень допомоги та визначить, як завдання виявляє реальне розуміння. Він запитуватиме лише про критично важливі відсутні відомості, які безпосередньо впливають на педагогічний дизайн.
