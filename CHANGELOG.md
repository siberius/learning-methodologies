# Changelog

All notable changes to this project.

## [1.0.0] — 2026-09-23

- Initial release.
- Single-file portable skill `learning-methodologies.md` (frontmatter:
  `name`, `description`).
- Methods: audience/tone elicitation, generational communication (Gen Z/Alpha),
  Socratic method (elenchus, Paul & Elder, AI-guided discovery), Bloom's
  taxonomy (gradation remember→create), AI-assisted learning modes (Feynman
  technique, Zone of Proximal Development with fading scaffolds, inquiry-based
  learning, role-play), further pedagogic methods (gamification, spaced
  repetition, scaffolding, error-based learning) and assessment forms
  (summative, formative, portfolio, adaptive…).
- Docs: README, USAGE (decision matrix + per-agent installation), TEACHERS
  (what each method is + ready-to-use prompts).
- MIT license.
